# snapspot

A playful, browser-only photo booth built with HTML, CSS, and vanilla JavaScript.

## Run locally

Camera access requires a secure context. From this directory, start a local server:

```sh
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) and allow camera access when prompted. No dependencies or backend are required. Photos are kept in the current page and can be downloaded individually.
